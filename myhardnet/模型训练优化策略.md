## 优化器决策

默认使用带 momentum 的 SGD，并开启 Nesterov；AdamW 保留为可配置对照。

| 方法 | 核心思想 |
| --- | --- |
| SGD | 使用当前梯度更新参数 |
| Momentum | 累积历史更新方向 |
| Nesterov | 在预估位置计算修正梯度 |
| AdamW | 自适应学习率与解耦 weight decay |

HardNet 的 hardest-in-batch 度量学习优先以 SGD 的最终泛化能力为基线，不能仅根据短程收敛速度切换优化器。

## 学习率调度

使用带预热的余弦退火。

## 实施状态

1. 固定验证协议
- `R0/R1/R2` 不合并，完整 `finger_id` 作为物理手指身份。
- 由 `validation.seed` 确定性抽取 16,384 条不重复正样本记录。
- 每个 anchor 固定选择 32 个同指纹、不同 `point_group` 的负样本，以及 32 个跨完整 `finger_id` 的负样本。
- 负样本按不同真实位置无放回抽取，不重复补齐；训练期随机 sampler 不再用于验证。

2. 验证指标
- 主选模与 early stopping 字段为 `val_fpr_at_tpr95`。
- 总体指标包含：`val_recall_at_1`、`val_tpr_at_fpr_1e_4`、`val_roc_auc`、`val_eer`、`val_pos_p95`、`val_pos_p99`、`val_neg_p01`、`val_neg_p05`、`val_active_triplet_ratio`。
- 同指纹和跨指纹分别输出 `val_same_finger_*`、`val_cross_finger_*` 指标。
- `Recall@1` 的候选集合为每个 anchor 的 1 个正样本和固定 64 个负样本；这些是 patch 层固定采样指标，不替代完整指纹匹配层 FAR/FRR 评估。

3. 优化器和参数分组
- 默认使用 `SGD + momentum + Nesterov`，可通过 `optimizer.name: adamw` 切换到 AdamW。
- Conv/Linear 权重应用 `weight_decay`；BatchNorm 参数和所有 bias 使用 `weight_decay=0`。
- 更换优化器或启用新验证协议时必须使用新输出目录从头训练，不恢复旧 optimizer state。

```yaml
optimizer:
  name: sgd
  lr: 0.1
  momentum: 0.9
  nesterov: true
  weight_decay: 0.0001

validation:
  protocol: fixed_pairs_v1
  seed: 10042
  positive_count: 16384
  same_finger_negatives_per_anchor: 32
  cross_finger_negatives_per_anchor: 32
```

切换 AdamW 时应同时显式设置实验学习率，例如 `name: adamw`、`lr: 0.001`；程序不会根据优化器名称静默改写学习率。

4. 实验记录与兼容边界
- 命令行覆盖会先回写实际配置，再保存到 `resolved_config.json` 和 checkpoint，修复目录名与实际 batch size 可能不一致的问题。
- 新实验默认输出到 `outputs/hardnet_train_mobile_fixed_v1`，避免混入旧指标 CSV。
- 旧模型 checkpoint 的推理加载兼容保留；旧指标 CSV 不再兼容续写。
