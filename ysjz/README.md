# 衍射校准与复原（ysjz_V4）

## 1. 脚本作用

`ysjz_V4.py` 对超声采集的多帧差分指纹图像做衍射相关复原，把同一组（同一 `pair`）中的 5 张不同采样时刻图像合成为一张可用于后续识别或去噪的灰度图。

大致流程：

```text
多帧原始 BMP（同一 pair，5 个 Rgd）
        ↓
复数解调（按采样时刻做相位叠加）
        ↓
行/列均值校正
        ↓
衍射逆卷积（按膜厚构造逆核）
        ↓
相位优化 + 归一化
        ↓
输出单张 pair_*.bmp
```

它不训练网络，也不做身份匹配，只做采集端到可用指纹图之间的物理复原预处理。

## 3. 前置条件

运行前请确认：

1. 已安装上述 Python 依赖。
2. 输入目录存在，且其下按“手指/样本文件夹”分子目录存放 BMP。
3. 每个 `pair` 必须凑齐以下 5 个采样编号（`Rgd`）：

   ```text
   1421, 1423, 1425, 1427, 1429
   ```

4. 文件名需能被脚本识别，推荐格式：

   ```text
   diff-pair_1-Rgd=1421.bmp
   diff-pair_1-Rgd=1423.bmp
   diff-pair_1-Rgd=1425.bmp
   diff-pair_1-Rgd=1427.bmp
   diff-pair_1-Rgd=1429.bmp
   ```

   关键点：文件名中同时包含 `diff-pair_{编号}` 与 `Rgd={上述五个值之一}`。

5. 脚本顶部的 `INPUT_DIR`、`OUTPUT_DIR` 已改成你本机的真实路径。

缺任一 `Rgd` 的 pair 会被跳过并打印提示，不会中断整批处理。

## 4. 输入输出

### 输入目录结构

`INPUT_DIR` 指向父目录，其子文件夹各自独立处理：

```text
INPUT_DIR/
├── sample_A/
│   ├── diff-pair_1-Rgd=1421.bmp
│   ├── diff-pair_1-Rgd=1423.bmp
│   ├── ...
│   ├── diff-pair_2-Rgd=1421.bmp
│   └── ...
└── sample_B/
    └── ...
```

脚本会：

- 扫描 `INPUT_DIR` 下所有一级子文件夹；
- 在每个子文件夹内按 `pair` 编号分组；
- 仅处理五个 `Rgd` 齐全的 pair。

### 输出目录结构

结果写到 `OUTPUT_DIR`，保持与输入子文件夹同名：

```text
OUTPUT_DIR/
├── sample_A/
│   ├── pair_1.bmp
│   ├── pair_2.bmp
│   └── ...
└── sample_B/
    └── ...
```

每个成功复原的 pair 对应一张 `pair_{编号}.bmp`（8 位灰度）。

## 5. 如何运行

### 5.1 修改路径与主要参数

打开 `ysjz_V4.py` 顶部：

```python
INPUT_DIR = r"D:\你的原始多帧BMP父目录"
OUTPUT_DIR = r"D:\你的复原结果目录"
```

常用物理与处理参数（一般先保持默认，再按设备标定微调）：

| 参数 | 含义 | 当前默认 |
|------|------|----------|
| `FREQ` | 超声频率（Hz） | `11.364e6` |
| `SOUND_SPEED` | 声速（m/s） | `4000.0` |
| `DPI` | 成像分辨率 | `338.0` |
| `BASE_THICKNESS` / `D_OFFSET` | 膜厚相关量（米） | `0.0010` / `0.0` |
| `DELTAT` | 采样时间相关参数 | `62500000.0` |
| `SAMPNUM` | 参与解调的帧数 | `5` |
| `DO_BLOCK_CORRECTION` | 是否做校正（当前分支效果上都会走全局行/列校正） | `True` |

### 5.2 启动命令

在项目目录执行：

```powershell
cd C:\Users\ZYH\Desktop\harnet32\ysjz

```

运行时会打印：

- 发现多少个数据子文件夹；
- 每个文件夹内发现多少个 pair；
- 哪些 pair 因缺帧被跳过；
- 哪些 pair 处理成功或失败；

### 5.3 结果检查

- 成功：对应子目录出现 `pair_*.bmp`。
- 缺帧：终端出现 `缺少文件: [...]`，该 pair 无输出。
- 读图失败或文件名无 `Rgd=`：该 pair 报错后继续处理下一个。

## 6. 方法简介

脚本核心类是 `DiffractionCalibrator`，步骤如下。

1. **多帧解调**  
   将 5 张按 `Rgd` 排序的灰度图按采样时刻叠加成复数场，相当于把时间采样合成复振幅。

2. **行/列校正**  
   减去全局行均值与列均值，减轻条带状背景或通道偏置。

3. **衍射逆卷积**  
   按设定厚度与声速构造空域逆核，对复数场做频域卷积式反卷积，减弱衍射模糊。

4. **相位优化与落盘**  
   估计整体相位校正，取实部，必要时翻转符号，再线性拉伸到 0～255 写成 BMP。

因此，输入应是“同一接触条件下、固定 5 个采样时刻”的一组差分图；输出是一张已复原的指纹灰度图，可再交给去噪或匹配流程。

## 7. 使用建议

1. 先用少量完整 pair 试跑，确认输出对比度、纹理是否合理。
2. 设备参数（频率、声速、厚度、DPI）应与采集系统一致，否则复原可能发糊或发虚。
3. 批量跑之前备份原始数据；输出目录已有同名 `pair_*.bmp` 时会被覆盖。
4. 后续若接到 `denoising` 或 `myhardnet`，请把 `OUTPUT_DIR` 下生成的 `pair_*.bmp` 作为其输入图像源。
